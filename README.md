## Introdução: 🧾
> No mundo atual é indispensável o uso de ferramentas e tecnologias de gestão para as nossas tarefas do dia a dia.
> O projeto Shopping Iguatemy, busca sempre inovações para atender as demandas e necessidades do seu público, e aposta no Software, de Gestão, para organização e otimização em suas diversas tarefas de apoio a sociedade, de Olinda em Pernambuco.</p>


## Objetivo do Software: 🎯
> O software fará a organização de forma sistemática das vendas de seguimentos, Vestuário, Perfumária, e Joalheria reduzindo erros e trazendo mas segurança e detalhamento do item que foi comprado, qual loja e seu valor gasto por seguimento, dentre outras melhorias.


## Funcionalidades: ⚙️
> O Software de Gestão multiplataformas está apto para o sistema operacionais: Windows, Linux, IOS, e Android, desenvolvido em uma linguagem já consolidada no mercado e aprovada por milhares de usuários no mundo.
